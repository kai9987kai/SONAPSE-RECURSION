# Virtual communication

Two scalar neural encoders and decoders exchange independent values in both directions. Updates use reconstruction residuals during training. Frozen, decoder-only and reciprocal training arms share initialization, training values and test values. All quantities are dimensionless synthetic signals.

A separate external-memory experiment gives a four-cell host access to a sixteen-cell external reservoir, either immediately or after two ticks. A decoder predicts the input from four ticks ago. The delayed channel itself supplies a helpful temporal offset. This is an important alternative explanation for a delayed advantage. The external reservoir has an explicit additional cell and bandwidth budget. Physical interfaces and patient data are outside the experiment.
