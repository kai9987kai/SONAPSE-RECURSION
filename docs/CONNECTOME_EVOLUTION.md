# Connectome evolution

A six-cell reservoir must reconstruct an input three ticks later. Each candidate fits its own readout on the first segment. Twenty mutations change or remove a recurrent edge. Validation error on a disjoint segment determines whether a child becomes the parent. A final untouched segment scores the incumbent. The independent-search control applies the same mutations to the original parent and retains its best candidate.

The browser replays actual validation errors and accepted changes for seed zero. The separate Pareto study grows, prunes and mutates neural feature populations and retains candidates nondominated in validation error and parameter count. Explicit crossover and transfer between task families remain future experiments. The current experiment models inheritance of recurrent weights with fresh readout fitting.
