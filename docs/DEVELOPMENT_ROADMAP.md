# Development plan and next priorities

The foundation is an independent reference, learned transition, held-out autonomous rollout and executable control. Subsequent slices add graft and hierarchy studies, bounded state governance, synthetic survival, architecture mutation, bidirectional adaptation, delayed prediction, storage and offline visualization. The benchmark suite exposes each slice independently.

1. Address hybrid discontinuities first. Fit event-aware spike and collision transitions. Before training, specify held-out trajectories, spike timing tolerances and rollout failure thresholds. Compare with the current saturated and linear controls.
2. Replicate graft utility on native tasks distinct from the pretraining target, with complete inference, training and memory accounting. Match both total cells and total multiply-adds across controls.
3. Test genuine recursive instantiation. Require a represented child to select a novel grandchild description, demonstrate causal dependence on child state, and compare against a flat capacity- and compute-matched host.
4. Extend the river environment with delayed hazard observation, learned planning and independent sweeps of energy costs and resource deadlines.
5. Extend the OpenWorm importer to additional measured datasets and widen the sampled circuits. Scale the sparse event substrate beyond its current 4,096-node benchmark. Add independently learned virtual clocks, broader Pareto objectives, learned uncertainty calibration and optional GPU acceleration.
6. Expand interactive topology, lineage and live backend controls after defining stable streaming and replay schemas.

The full master specification also describes general processors, large connectomes, higher-fidelity physics, open-ended hypothesis discovery, a library of specialized grafts, and developmental neurogenesis. These remain implementation objectives. Six CLI profiles select studies, seed budgets and worker counts. Individual trials use identical dynamics in all profiles.
