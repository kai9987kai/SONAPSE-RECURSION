# Implementation coverage

This inventory distinguishes usable experiments from broader requirements in the master prompt. The release is a foundation for further experiments.

| Subsystem | Executable coverage | Remaining work |
|---|---|---|
| Host and target connectomes | Eight simplified fixed-step model families, signed delayed connections, separate sparse event substrate, public edge-list import | Calibrated morphology, measured physiology and compatible native SONAPSE graft execution |
| Neural VM | Learned recurrent transitions, binary programs, programmable structural rule, nested program binding | General processor, memory addressing and learned instruction sets |
| Computational imagination | Autonomous rollouts across mechanical, fluid, electrical, computational and neural references | High-fidelity mechanical and hydraulic validation |
| Creative and dual imagination | Bounded design mutation, recombination, acceptance and three interference conditions | Learned creative generator, dynamic partitioning and source monitoring |
| Grafts | Fixed-bank allocation, periods, activation, suspension, removal, state query, communication and trained readout | Self-selected graft construction and open-ended graft library |
| Recursion | Parent-child leases, depth enforcement, two clocks, distillation, corruption intervention and flat controls | A represented child independently selecting and constructing an unfamiliar grandchild |
| Evolution and plasticity | Modulated Hebbian updates, edge mutation, Pareto population growth and pruning, inherited weights | Developmental graph grammars, morphology evolution and complete archived population lineage |
| Automated research | Source-versioned trials, bounded template selection, disjoint replication seeds and stored selection protocol | Open-ended hypothesis generation and hard per-process memory enforcement |
| Governor | Five simultaneous budgets, protection, pre-emption, four scheduling rules and deterministic state recovery | Learned general-purpose scheduler and hardware thermal modeling |
| Communication and virtual BCI | Bidirectional scalar adaptation, external reservoir, delayed lossy transport, bounded predictions and closed-loop stress test | Universal adapters, richer learned codecs and integration of all interface conditions into one calibrated channel |
| Survival | Foraging and river crossing, eight crossing policies, paired quiet/hazardous environments and held-out evolved thresholds | Long-horizon learned embodied societies, cooperation and multi-agent navigation |
| Biological analysis | Explicit proxy assumptions, separate operation/parameter/state counts and anatomical source provenance | Biological calibration, measured power and comprehensive per-component instrumentation |
| Verification and benchmarking | Independent equations, causal deployment test, fresh inputs, held-out topology, matched controls and seed uncertainty | Larger preregistered experiments and independent replication |
| Visualization, storage and export | Offline replay, online local trial launch, interactive evolution replay, recorded results, SQLite cache, portable JSON checkpoints and trace download | Full live backend topology editing, 3D rendering and GPU profiling |

The browser and backend have different execution contracts. Browser neural trajectories use embedded frozen parameters, browser survival uses the simplified forager, and evolution replays a measured lineage. The local dashboard can additionally launch the Python studies. A faster display refresh or worker count changes presentation or scheduling only.
