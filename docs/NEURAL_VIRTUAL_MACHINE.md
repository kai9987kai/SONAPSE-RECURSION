# Neural execution modes

A uses conventional physics, rate equations or a finite-state truth table. B fits next-state examples with fixed random tanh features and a ridge-trained readout. Feeding the learned output back into the next step gives an explicit persistent state pathway (C). The projected features and readout together form the recurrent host. No teacher state is supplied after initialization in autonomous trials.

D has two restricted probes. In structural transfer, an unfamiliar weighted adjacency matrix determines conventional message routing and a learned local rule updates the state. In the binary machine probe, four description bits specify a one-bit machine's transition table. A learned neural readout updates its binary register, with an explicit hard threshold. Four held-out tables per seed test the learned multiplexer.

E is approached through nested distillation and a two-clock hierarchy. The training harness supplies the hierarchy and schedule. General-purpose neural instruction execution, automatic architectural instantiation and learned open-ended recursion remain research objectives.

The capability ladder used in this release is 0 representation, 1 prediction, 2 dynamical approximation, 3 autonomous simulation, 4 functional equivalence on unfamiliar conditions, 5 programmable emulation, 6 host use of virtual grafts, 7 internally learned recursive instantiation, and 8 adaptive recursive augmentation. Reports give task-specific observations. An autonomous rollout alone cannot certify levels 4–8.
