# Cognitive resource governor

The state bank protects a native prefix and grants contiguous leases within a parent. Siblings cannot overlap. Nested allocations reuse the parent's reservation. Suspending an ancestor disables descendants, and deletion clears state and releases its range. The interruption experiment freezes state for eight wall ticks, then resumes using the deferred drive sequence. Its reference runs the same number of virtual updates continuously.

The survival scheduler models attention availability explicitly. The protected condition assumes a dedicated attention lane. Busy and interruption conditions contend for one lane. The protected lane is an architectural assumption with a different effective processing budget. Counts of work ticks, interruptions, state cells and activity are simulation proxies. Trial process CPU time is measured separately.

The general dispatcher enforces independent operations, memory, bandwidth, simulated energy and attention budgets per quantum. Native reservations constrain background jobs. FIFO, priority, earliest-deadline and utility policies operate on identical job lists. Emergency dispatch suspends background work and expired jobs cannot consume a quantum. Completion and utility are compared separately in the governance study.
