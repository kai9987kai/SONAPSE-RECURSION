# Sensory imagination

Open the sensory section of the standalone dashboard. Choose **Feed example**, **Feed a video file**, or **Use webcam**. The included six-second Orbit, Ripple and Crossing WebM clips are original synthetic stimuli. They are embedded in the offline page. Input audio is unused. Camera tracks stop when switching inputs, stopping, starting autonomous imagination, or leaving the page.

Each fresh decoded frame is sampled at up to five ticks per second and reduced to a 20 × 12 RGB array. Eighteen spatial luminance receptors drive a sparse recurrent rate network. The graph displays its 54 directed signed edges and current node activation. A dot toward the receiving end marks direction. Green and orange edges indicate positive and negative weights. The three bars show the existing trained host's response to the mean sensory population drive.

Each observed episode stores a source label, sequence number, color array, sensory state and three trained host activations. At most 240 observations are retained in chronological order. A forecast retrieves the most similar prior observation with a known successor, using frame color, sensory state and trained host state. It blends the retrieved successor with the current frame plus the observed displacement in RGB values. Adjacent observations from different inputs or loop boundaries cannot form a training pair. The live display compares normalized RGB mean absolute error against holding the last observation. Sampling rate and browser decode timing can affect this measurement.

Select a remembered episode and press **Imagine from memory** to close the input and roll the forecast forward using its previous output. Hypothetical images remain outside the observation buffer. The first frames from a new installation need at least one observed transition before a forecast is available. The model can produce blur, repeated images or drift. It has no object recognizer or natural-language scene understanding.

**Save visual memory locally** retains the bounded sample in this browser origin across reloads. Saving a new snapshot replaces the previous snapshot. **Export visual memory** downloads JSON with low-resolution frames, source names and states. These frames may still depict identifiable content. Full-resolution video, audio and camera streams are never uploaded by this workspace. **Clear visual memory** removes saved and active observations after confirmation. Localhost ports and file origins have separate browser storage.

The three example clips can be regenerated with `python scripts/make_sensory_clips.py` using NumPy and the optional imageio-ffmpeg package. The checked-in clips suffice for the usual `python scripts/build_demo.py` build. The test in `tests/sensory_smoke.py` exercises all three decoder paths with Chromium's synthetic webcam.

To validate a downloaded session independently, run `python scripts/visual_replay.py sonapse-visual-memory.json` from the project root. It reconstructs receptor and trained host trajectories from pixels and reports maximum absolute state disagreement. A ring buffer that starts mid-episode uses its oldest retained neural state for initialization.
