# Dual imagination

The design study proposes bounded stiffness and damping pairs by recombining previous accepted candidates and mutating them. A separate oscillator evaluates proposals on six forcing sequences. Acceptance uses training cost; final cost uses six new sequences. Designers cannot edit the simulated oscillator's authoritative trajectory. Thirty-two proposals bound the search.

The interference study instead asks what happens when unrelated activity reaches an active state. Shared, partially gated and isolated conditions inject the same noise stream with gains 1, 0.5 and 0. Lower error in an isolated state measures the intervention by construction. It does not establish that a neural host can learn to isolate a workspace. Learning the gate from task outcomes is an open experiment.
