# Recursive emulation

The nested study first fits a host to a two-cell target. A second host then learns transitions generated by that trained host. During evaluation each runs independently. Comparisons against both the target and the inner host expose compounded approximation error. An eight-cell parent reservation includes the child's two coordinates. Counting both as separate allocations would overstate physical state occupancy.

In the hierarchy study a parent maintains a native task, a binary phase and a two-coordinate child. The child advances every second tick. A single outer neural transition learns the combined state trajectory. The direct control has the same model width, projection, training drives and amount of supervision, with a conventional ground-truth child supplying training labels. Both are evaluated on the same reference. The learned rollout does not call a child interpreter.

The outer host learns an experimenter-defined structure. Learned instantiation by a virtual system and an advantage from increasing depth have yet to be demonstrated.

## Program-binding intervention

The binding experiment trains an inner neural kernel to load or retain two opcode bits and update a one-bit accumulator. An outer kernel learns from the inner kernel's responses. Each held-out trace contains fourteen program loads in 256 commands. Flipping the retained opcode bits after loading tests whether subsequent behavior depends on bound program state. A flat kernel with identical features learns directly from the interpreter labels. Across eight seeds the distilled output accuracy was 98.73%, the flat control achieved 100%, and the corruption intervention yielded 33.69%. The experimenter chooses the command stream and the four primitives. Correct execution does not demonstrate autonomous invention of a child architecture.
